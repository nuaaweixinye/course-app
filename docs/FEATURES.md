## 1. 应用概述

**课表** 是一款面向中国大学生的 Android 课程表管理应用。支持多学期、多课表、多周次模式，可从 CSV / iCalendar / 南京航空航天大学教务系统导入课程，提供桌面小组件查看当天剩余课程。

**入口**: 启动后进入首页课表网格，通过底部导航栏切换"课表 / 任务 / 设置"三个页面。

## 2. 首页课表

| 功能 | 说明 |
|------|------|
| **7×12 网格** | 周一至周日 × 12 节次，自定义 `TimetableView` 绘制 |
| **课程卡片** | 显示课程名（2 行）+ 上课地点，左侧 8 色调色板标记 |
| **日期标签** | 每列顶部显示日期（M/d），根据学期开始日期 + 当前周次计算 |
| **今日高亮** | 当前周次下高亮今天所在列，标注当前正在进行的节次 |
| **无课日期变暗** | 当天没有课程的列以低对比度显示 |
| **空状态** | 无活跃课表时显示"没有课表"；有课表但本周无课时显示"本周没有课程，点击 + 添加" |
| **周次切换** | 上一周 / 下一周按钮 + 数字输入框，输入后自动聚焦校验并隐藏键盘 |
| **"本周"按钮** | 工具栏菜单，一键跳转到当前周次 |
| **点击课程** | 跳转到课程详情页 |
| **活跃课表名** | 工具栏下方显示当前活跃课表名称 |

### 工具栏菜单

| 操作 | 图标 | 行为 |
|------|------|------|
| 添加课程 | ➕ | 跳转到课程编辑页（新建模式） |

## 3. 课程管理

### 3.1 新建/编辑课程 (`CourseEditActivity`)

| 字段 | 类型 | 说明 |
|------|------|------|
| 课程名 | 文本 | 必填 |
| 教师 | 文本 | 选填 |
| 备注 | 文本 | 选填 |
| 颜色 | 8 色色块 | 点选，默认循环分配 |
| 课表 | 下拉 | 当前学期的课表列表，可选"无课表" |
| 上课时间 | 动态行 | 可添加多条，每条包含：星期 / 起始节次 / 结束节次 / 地点 / 周次模式 |

**周次模式预设**: 全周 (1-16) / 单周 (1,3,5,...) / 双周 (2,4,6,...)

**校验规则**:
- 课程名不能为空
- 至少一条上课时间
- 结束节次 ≥ 起始节次

### 3.2 课程详情 (`CourseDetailActivity`)

- 顶部显示颜色条、课程名、教师、所属课表、备注
- 列出每条上课时间：星期节次 / 地点 / 周次模式
- **周次条**: 可视化显示该 session 在哪些周有课（彩色圆点）
- **例外摘要**: 显示"停课 N 次，调换 M 次"
- 点击一条上课时间 → 打开周次例外管理对话框

**工具栏菜单**: 编辑 / 例外 / 删除（删除前确认）

### 3.3 课程列表 (`TimetableCourseListActivity`)

- 展示某个课表下的所有课程
- 点击课程 → 跳转到编辑页

## 4. 周次/例外

### 4.1 周次模式 (WeekPattern)

支持以下格式（兼容导入解析）:

| 格式 | 含义 | 示例 |
|------|------|------|
| `a-b` | 连续范围 | `1-16` |
| `a,b,c` | 枚举 | `1,3,5,7` |
| `a-b,c-d` | 混合 | `1-5,8,10-12` |

### 4.2 单周例外 (SessionException)

对某条上课时间在特定周设置例外，**不修改原始周次模式**:

| 类型 | 说明 |
|------|------|
| **停课 (CANCEL)** | 该周此课不显示 |
| **调换 (MOVED)** | 该周此课改到另一天 |

**操作方式**: 课程详情 → 点击某条上课时间 → 例外管理对话框 → 添加（选类型/周次/目标天）/ 删除已有例外

## 5. 学期管理

`SemesterManageActivity` — 管理多个学期。

| 操作 | 说明 |
|------|------|
| 新建学期 | 输入名称，自动设为活跃学期 |
| 编辑学期 | 修改名称 / 开始日期 / 总周数 |
| 删除学期 | 确认后删除（级联删除该学期下的课程和课表） |
| 管理课表 | 跳转到该学期的课表管理页 |

**学期切换规则**: 独立的"设为当前学期"功能已移除。学期切换只通过课表切换间接完成——切换课表时自动切换活跃学期。

**学期属性**:
- **名称**: 用户自定义
- **开始日期**: 学期第一周的周一（自动取整）
- **总周数**: 默认 16
- **节次时间**: 12 节的时间表（JSON 格式，可编辑）

## 6. 课表（timetable）管理

`TimetableManageActivity` — 管理某学期下的多个课表。

| 操作 | 活跃课表 | 非活跃课表 |
|------|----------|------------|
| 设为当前 | — | ✅ 切换为活跃，同时切换所属学期为活跃学期 |
| 查看课表 | ✅ | ✅ |
| 重命名 | ✅ | ✅ |
| 删除 | ✅ | ✅ |
| 导入 | ✅ 工具栏 | ✅ 工具栏 |

**活跃课表联动逻辑**:
1. 用户在课表管理中点击"设为当前"
2. `TimetableRepository.switchTo(id, semesterId)` 同时执行：
   - 清除该学期其他课表的 `isActive`
   - 设置目标课表 `isActive = 1`
   - 清除所有学期的 `isActive`
   - 设置目标学期 `isActive = 1`
3. `MainViewModel` 观察到活跃学期变化 → 重新观察新课表的活跃课表
4. `CourseRepository` 的 `activeTimetableId` LiveData 触发 → `observeWeekSessions` 重新执行 `combine()` → 首页课表刷新

## 7. 批量操作

在首页网格中**长按**课程卡片进入多选模式。

| 操作 | 说明 |
|------|------|
| 批量删除 | 确认后删除选中课程（级联删除 session + exception） |
| 批量移动 | 选择目标课表，将选中课程移入 |
| 批量停课 | 占位功能，暂不可用（提示 Toast） |

选择栏显示已选数量，点击"关闭"退出多选模式。

## 9. 课程导入

支持三种导入格式，均带预览确认步骤。

### 9.1 CSV 导入

- **入口**: 设置 → 导入帮助 / 其他应用分享文件 / 课表管理工具栏导入
- **识别表头**（中英文自动映射）:

  | 识别关键词 | 字段 |
  |-----------|------|
  | 课程/课程名/课程名称/名称/name/course | 课程名 |
  | 教师/老师/任课教师/teacher | 教师 |
  | 星期/周/周几/day/weekday | 星期 |
  | 起始/开始/开始节次/start | 起始节次 |
  | 结束/结束节次/end | 结束节次 |
  | 教室/地点/位置/location/room | 地点 |
  | 周次/weeks/weekpattern | 周次模式 |

- 支持带引号的 CSV 字段（内含逗号/引号）

### 9.2 iCalendar (.ics) 导入

- 解析 `VEVENT` 事件
- 根据事件开始时间匹配最近的节次
- `RRULE COUNT=N` → 第 1~N 周；无 RRULE → 默认 1-16 周

### 9.3 NUAA 教务系统导入

- **文件方式**: 课表管理工具栏导入，选择教务系统导出的 HTML/XLS 文件
- **WebView 登录方式** (`WebViewLoginActivity`): 应用内打开教务系统登录页，用户完成 CAS 登录后自动抓取课表页面 HTML 并解析
  - 使用桌面 Chrome UA
  - 应用不接触用户密码
  - 通过 Cookie 提取 + HTTP 重定向跟随获取课表页
  - 已在 manifest 注册，但当前 UI 流程中未接入入口

**解析逻辑** (`NuaaEamsParser`):
- 解析页面内嵌 JavaScript 中的 `new TaskActivity(...)` 调用
- 提取课程名/教室/教师/周次
- 将教务系统 13 槽位时间表映射为 12 节次（午间槽位跳过）
- 合并连续节次为一条 session

### 9.4 导入目标

| 入口 | 导入到 |
|------|--------|
| 文件分享/打开 (`ImportActivity`) | 当前学期的"未分配"区（无课表） |
| 课表管理工具栏 (`TimetableManageActivity`) | 自动创建新课表，文件名作为课表名 |

## 10. 课表导出

- **入口**: 设置 → 导出课表
- **格式**: CSV（与 CSV 导入格式兼容，支持往返导入）
- **内容**: 所有课程 + 上课时间
- **方式**: 系统文件选择器 (SAF) 选择保存位置

## 11. 桌面小组件

| 属性 | 值 |
|------|-----|
| 尺寸 | 最小 110dp，2×2 单元格 |
| 刷新间隔 | 30 分钟 |
| 内容 | 今天尚未结束的课程 |

**显示逻辑**:
- 计算当前周次 + 今天星期几
- 加载全部 session + exception
- 应用周次模式过滤 + 例外处理（与首页网格一致）
- 仅显示今天且未结束的课程
- 点击任意条目打开应用首页

**手动刷新**: 课程变更（删除/导入）后自动通知小组件更新。

## 13. 节次时间配置

设置 → 节次时间编辑器。

- 默认 12 节，每节有开始/结束时间
- 点击某节弹出时间选择器
- 确认后序列化为 JSON 存储

**默认时间表**:

| 节次 | 开始 | 结束 |
|------|------|------|
| 1-2 | 08:00 - 08:45 / 08:55 - 09:40 | 上午 |
| 3-4 | 10:00 - 10:45 / 10:55 - 11:40 | 上午 |
| 5-6 | 14:00 - 14:45 / 14:55 - 15:40 | 下午 |
| 7-8 | 16:00 - 16:45 / 16:55 - 17:40 | 下午 |
| 9-10 | 19:00 - 19:45 / 19:55 - 20:40 | 晚间 |
| 11-12 | 20:50 - 21:35 / 21:45 - 22:30 | 晚间 |

## 14. 数据架构

### 14.1 数据库 (Room, v5)

```
App (Application)
 └─ AppDatabase (单例)
      ├─ CourseDao         → courses
      ├─ CourseSessionDao  → course_sessions
      ├─ SessionExceptionDao → session_exceptions
      ├─ TaskDao           → tasks
      ├─ SemesterDao       → semesters
      └─ TimetableDao      → timetables
```

### 14.2 实体关系

```
SemesterEntity (1) ──< TimetableEntity (N)
       │                    │
       │ (1)                │ (1)
       │                    │
       └──< CourseEntity (N) ──> (timetableId 可空)
                │
                │ (1)
                │
                └──< CourseSessionEntity (N)
                         │
                         │ (1)
                         │
                         └──< SessionExceptionEntity (N)

CourseEntity (1) ──< TaskEntity (N)  (courseId 可空, 删除时 SET NULL)
```

### 14.3 数据库迁移历史

| 迁移 | 版本 | 内容 |
|------|------|------|
| MIGRATION_1_2 | 1→2 | 单行配置表 → 多行 semesters 表；courses 增加 semesterId |
| MIGRATION_2_3 | 2→3 | 新建 timetables 表；解析旧 timetableProfiles 字段为独立行 |
| MIGRATION_3_4 | 3→4 | 重建 timetables/courses 表（name 可空，清理遗留列） |
| MIGRATION_4_5 | 4→5 | timetables 增加 isActive 列（每学期一个活跃课表） |

### 14.4 关键数据流

```
用户切换课表
  → TimetableRepository.switchTo()
    → 更新 timetables.isActive + semesters.isActive
      → SemesterDao.observeActive() 触发
        → MainViewModel.onDbSemesterChanged()
          → onSemesterChanged()
            → applyConfig() (更新周次/节次)
            → observeActiveTimetableForSemester() (重新观察)
              → TimetableDao.observeActive() 触发
                → courseRepository.setActiveTimetableId()
                  → activeTimetableId LiveData 触发
                    → observeWeekSessions combine() 重新执行
                      → 首页网格刷新
```
